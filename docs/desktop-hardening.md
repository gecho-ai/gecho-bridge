# 桌面端守护能力

更新：2026-10-11；版本：1.1.38；分支：feature/phase3-scheduled-desktop

## 已实现

| 能力 | 行为与边界 |
|---|---|
| 环境自检 | 检查本地 Bridge、插件连接、浏览器、磁盘及可选网络连通性；不把网络连通等同于浏览器代理可用，也不声称检测出所有防火墙问题 |
| 浏览器选择 | 探测 Chrome、Edge、Brave、Arc 的已安装路径及 Profile 标签；不读取 Cookie；选择后打开连接引导，仍需对应浏览器安装扩展 |
| 有限恢复 | 默认关闭；用户开启后，失联宽限 30 秒、尝试间隔 60 秒、最多 3 次；不杀掉用户浏览器，不保证恢复任意页面或会话 |
| 电源管理 | 实际运行的采集任务阻止系统空闲睡眠，空闲释放；唤醒刷新连接；不保证合盖、关机或强制休眠时继续采集 |
| 端口与归属 | HTTP 备用端口写入发现文件，客户端跟随；不误认其他服务；MCP/CLI 不会自动关闭桌面端管理的 Bridge；WebSocket 仍沿用现有协议端口 |
| 低存在感 | 关闭控制面板销毁窗口，重新打开再创建；没有未经测量的 40–60MB 内存承诺 |
| 系统融合 | 跟随系统深色模式；可选 Command/Ctrl+Shift+G；真实任务完成、失败和显式验证码事件触发去重通知，点击打开面板 |
| 排障日志 | 桌面日志默认 5MB × 4 个文件、保留 7 天；凭证脱敏，支持导出诊断；不是所有 Bridge 控制台输出的完整归档 |
| 更新 | 稳定版本筛选、平台/架构匹配、受限下载、失败清理、可选 SHA256 校验、安装启动失败保留应用；详见更新指南 |
