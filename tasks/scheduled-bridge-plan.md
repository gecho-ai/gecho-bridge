# Bridge 自动飞轮开发计划

## 目标

让官网保存的自动飞轮任务在本机 Bridge 中可靠保存、按时触发，并向浏览器插件发送“启动官网任务”的即时指令。Bridge 不负责官网业务编排、采集过程或最终结果。

## 开发切片

1. 任务模型与时间规则：每日/每周/单次、时区、错过执行策略、下一次执行时间。
2. 本地持久化与管理接口：创建、查询、修改、暂停、删除、立即触发、运行记录。
3. 触发协议：到点后启动或唤回浏览器，向插件发送稳定的 `start_flywheel_task` 指令，只记录即时派发结果。
4. 恢复与验证：Bridge 重启恢复任务，验证浏览器/插件未连接、重复触发和任务版本更新。
5. 独立运行：提供不依赖 MCP 的 Bridge 服务启动、停止、重启和状态命令。
6. 用户级开机启动：提供 macOS LaunchAgent、Linux systemd user、Windows 登录任务的显式安装/卸载能力。
7. 文档：补充接口契约、服务生命周期、开机启动和当前能力边界。

## 明确不做

- Bridge 不保存或执行一键成片的业务步骤。
- Bridge 不等待脚本/视频生成，也不接收最终业务结果。
- 暂不处理系统睡眠唤醒、桌面助手 UI 和桌面安装器包装。
- 插件页面就绪判断和官网启动入口由前端/插件负责。
